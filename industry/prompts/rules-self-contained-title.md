
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：装备型号 / 系统或软件名 / 公司名 / 项目名 / 研究主体。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "v2.1"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "v2.1" + 来源和正文明确是某农场管理软件的发布说明 → "某农场管理软件 v2.1 发布"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体型号时，用上位词（如“自动转向终端”）兜底，绝不凭“行业常识”编一个具体型号 / 版本 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Trial 这类解释、分析、教程、评测或试验标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的装备、平台或新数据，就改写成“发布 / 推出 / 上线 / 开源”。只有原标题明确宣布了发布、推出、上线或开源，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、产品、项目名。
   例：原标题“某喷洒机器人如何识别杂草” → “某喷洒机器人如何识别杂草”，不能写成“某厂商发布喷洒机器人”。
   例：原标题“How to import prescription maps” + 来源和正文明确名为“示例终端 T1” → “示例终端 T1 如何导入处方图”，不能只写成缺主体的“如何导入处方图”。
6. 宣称、演示、试验与交付阶段不能升级改写。原标题是厂商介绍或演示时，不能把标题写成田间效果已经被验证；研究标题有地区、作物或样本限制时保留核心限制。
