# PrecisionAGHOT 行业包

这里定义全球精准农业科技、装备、软件与服务的行业配置。网站使用 **PrecisionAGHOT** 品牌，行业范围包括导航与自动转向、智能终端与变量作业、无人机与机器人、遥感/物联网、水肥管理、FMIS/FMS/农场 ERP、数据平台和技术服务。

配置和运营边界见 [精准农业版本说明](../docs/precision-agriculture.md)，通用修改方法见 [行业定制](../docs/customize.md)。

| 文件 | 内容 |
|---|---|
| `site.ts` | 站名、行业词、首页文案、关于页、备案号 |
| `taxonomy.ts` | 分类、标签、公司与机构、防止模型写错主体的身份词表 |
| `topics.json` | 主题目录（`/topics`），覆盖公司机构、技术方向与内容形态 |
| `sources.json` | 首次启动时导入的全球农业科技候选信源，已有信源不会被覆盖 |
| `prompts/` | 预筛、评分、写作、结构化、归组、综述、日报和翻译 |
| `selection.ts` | 保留原始入选门槛，等待行业样本校准 |
| `features.ts` | 模型榜与 Codex 重置监控在本版本关闭 |
| `brand/` | 独立图标、Logo、日报/周报/月报报头 |
| `pages/` | 使用规则和隐私说明模板，公开部署前需运营者确认 |
| `changelog.json` | 更新日志 |
| `gold.example.jsonl` | 农业行业精选评测格式示例，不能代替实际标注集 |

公开内容默认只提供摘要与原文链接，不默认转载全文。信源清单、重要性标准和噪声规则是初始方案；上线前需要运营者确认并用真实样本评测。
